Use them at **Новая заявка**: leave the files empty, paste the ORCID into the **ORCID** field (and the name into
**ФИО**), press **Сформировать досье**. The dossier is built from public sources only (ORCID, OpenAlex,
SJR). The **unit on the right is known**, so you can check whether the ITMO-unit recommendation finds it.
Without an application form the tool does not know the host unit, so compare by eye.
